## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) validates `POST.json` and copies it byte for byte to `$MAKEFUN_OUTPUT_DIR/POST.json`, where the house reads the post's address and fetches its counts. No network, no clock, no randomness — two runs write identical bytes.
